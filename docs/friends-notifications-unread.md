# 好友申请、通知、emoji 和未读计数

本次只修改源码并测试，不生成 WAR。

## 更新数据库

新增好友申请表，现有用户、好友关系和聊天记录继续保留。部署新版代码前，先在服务器的 `yytf_support` 数据库执行本项目的 `db/friend-requests.sql`。假设已经上传到当前目录：

```bash
mysql -h127.0.0.1 -u yytf_support -p yytf_support < friend-requests.sql
```

该文件可重复执行。只创建新表，无须重跑旧的 `db/migration.sql`，也不需要改动 Tomcat 的 `server.xml`。未执行时，通知和好友操作会提示失败，详细原因写入 Tomcat 日志。

新版部署后重新登录，让本次登录的未读起点生效。升级前已经建立的会话没有登录起点，其未读计数会从第一次访问聊天相关接口时开始。

## 使用方式

- 群聊中点击别人的头像，打开“添加好友”，点击“发送好友申请”。自己的头像不会显示申请按钮。
- 首页原来的添加好友入口也改为发送申请。重复申请不会创建多份；如果对方先申请了，提示前往通知处理。
- 聊天侧栏的“通知”位于“好友列表”上方。接收人可以同意或拒绝；同意后才建立双向好友关系并允许私聊。通知每 5 秒更新，超过 50 条可加载更早通知。
- 接受后好友列表自动更新。已拒绝的申请可以重新发起；旧申请不能重复同意来恢复已删除的好友。
- “发送”左侧的 😀 打开表情选择器，原始清单收录 Unicode Emoji 18.0 的 3,963 个标准序列及 9 个肤色、发型组件，共 3,972 项。首次打开时按当前设备实际字体检测，自动隐藏缺字方块、空白及无法合成的组合表情；电脑和手机上显示数量可能不同。支持分类、中英文关键词和直接输入 emoji 搜索，每页 24 个。清单及检测结果在当前页面内复用，无须访问第三方网站；加载失败可重试。
- 屏幕空间不足时，表情区域可滚动，搜索与翻页按钮保持可见。在消息当前光标处插入完整序列（包括设备支持的肤色、旗帜和多人组合），选中文字时替换选中部分；搜索按回车和选择表情都不会提交消息。支持 Esc 关闭，遵守原有消息长度上限。过滤只影响本机选择器，不改变或删除已有消息中的 emoji。
- “返回主页”位于群聊、私聊和通知页的右上角，使用与聊天主题一致的蓝色圆角按钮；左侧栏保留会话和通知入口。
- 群聊及每个好友都有红色未读数量。只累计本次登录后别人发来的消息，排除自己的消息和已删除消息；未经同意的陌生人不会进入私聊计数。
- 刷新页面、切换聊天、暂时停留在主页或个人资料不会重置本次登录的未读数。进入对应聊天且记录成功加载后清除，后台标签页不自动清除。
- 计数由数据库消息 ID 和会话内已读位置计算，WebSocket 重复推送或轮询不会重复累加。WebSocket 到达时刷新侧栏，也有每 5 秒一次的轮询兜底。同一浏览器会话的多个标签页共享已读位置；重新登录建立新的起点。
- 群聊/私聊新消息会播放 `sound/info.m4a`，后台标签页的标题每秒交替显示“收到新消息”，返回页面后恢复。首页、聊天室、通知和个人资料页面均启用到达检测；聊天页复用已有 WebSocket 和状态轮询，其他页面按 5 秒轮询。浏览器关闭或系统冻结页面时无法保证即时提醒。
- 浏览器要求先与页面交互才能播放声音。可点击“开启提示音”，也会在首次点击/键盘操作时尝试启用；按钮可关闭声音，静音偏好在本次登录期间保留。启用声音不会补播先前收到的消息。音频副本保存在 `src/main/webapp/sound/info.m4a`，部署时需包含它。
- 到达检测使用独立于未读数的 `latestIncoming`，避免另一标签页清除未读数后漏提醒；排除登录前、自己发送、删除或无好友关系的私聊消息。相同消息 ID 的推送/轮询只提醒一次，1.2 秒内的突发消息合并提示音，多标签通过 Web Locks 或 HTTP 下的本地存储协调播放。

## 验证

```powershell
.\mvnw.cmd -B test
node --test src/test/js/*.test.cjs

# 安装了 Playwright 的 Node 环境下；本机使用 Edge：
$env:PLAYWRIGHT_CHANNEL = 'msedge'
node --test src/test/browser/chat.browser.test.cjs src/test/browser/social.browser.test.cjs
```

Java 测试使用 H2 的 MySQL 模式执行新迁移及真实 SQL，覆盖申请/接受/拒绝/删除、并发和事务回滚、权限、登录未读起点与计数。Jasper 测试实际编译 JSP，浏览器测试使用其生成的 HTML 和真实脚本，HTTP/WebSocket 数据由测试模拟。未连接或修改线上数据库。

表情目录来源、许可证和重建步骤见 `tools/emoji/README.md`。表情专项回归覆盖原始清单与官方来源逐项一致、支持字形的全部页面可到达、分类/搜索、完整组合序列插入、加载失败重试、240 像素高视口滚动，以及桌面和手机的主页导航布局。消息提醒测试覆盖重复消息、私聊/群聊、HTTP 兜底、静音、标题恢复、多标签协调及实际 M4A 解码。

首页节假日倒计时按七类全国法定节日日期计算（不含调休），使用北京时间，当前节日结束后自动选取下一项。农历日期、清明节气和跨年数据的来源及重建方法见 `tools/holidays/README.md`。
