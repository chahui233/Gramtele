# 注册密码实时检查（2026-10-12）

注册页保留原来的十项要求，新增第十一项服务器随机哈希挑战。每次输入、删除或替换内容立即更新绿色 √ / 红色 ×，同时显示当前长度、数字总和、哈希计算结果和挑战剩余时间。手机端清单排列在输入区域下面。全部通过才允许提交；服务端 `RegisterServlet` 也验证相同规则，禁用或绕过前端无法绕过注册限制。既有账户登录不重新执行这套注册规则。

规则口径：

- 长度按 Unicode 码点计算，单个中文/普通 emoji 各为 1；组合 emoji、组合附加符分别计数，不按 UTF-16 长度计算第 1、9、10 项。
- 数字和大写字母分别限定为 `0–9`、`A–Z`。数字和统计整个密码，包括闰年、长度等数字。特殊符号使用 Unicode 标点/符号，不包含空格或换行。
- 月份匹配完整小写英文名称，允许作为更长字符串的一部分。
- 独立罗马数字使用大写标准形式，以空格或标点/符号分隔；字母、数字、组合附加符紧邻时属于同一词元。`VII` 是一个数，不拆分。恰好两个，乘积 35，可为 `I` / `XXXV` 或 `V` / `VII`，顺序不限；额外罗马数字或非标准罗马数字片段不通过。
- 闰年是完整的四位数字段，范围 1000–9999；能被 4 整除且不能被 100 整除，或能被 400 整除。更长连续数字中的四位子串不算。
- “包含实际长度”匹配实际码点数量的十进制字符串，可以出现在密码任意位置；1 不是质数。
- 保留原有认证输入上限 1024 个 UTF-16 单位，避免产生原登录接口不能接收的新密码。该上限独立于上述十项规则，页面输入框和服务器均执行，超限时不会注册。

第十一项的具体规则：

- 服务器使用 `SecureRandom` 生成随机串、挑战编号和 12 位十六进制目标前缀。
- 对 `随机串 + LF 换行符 + 原始密码` 的 UTF-8 字节计算 SHA-256，结果前 12 位必须与目标完全相同。密码不做 trim 或 Unicode 归一化；随机串不计入前十条规则。
- 匹配 12 位十六进制前缀相当于匹配 48 比特，单个候选密码匹配概率约为 `1 / 281,474,976,710,656`。满足全部条件就通过，没有额外随机拒绝。
- 为确保每题有解，服务器根据一个随机生成、满足前十项要求的参考密码计算目标前缀。参考密码不会下发、记录日志或保存到会话。
- 挑战与当前会话绑定，有效期 30 分钟；有效期内刷新或打开同会话的新标签页使用同一题。过期后刷新获取新题，不会在输入过程中悄悄换题。
- POST 只提交挑战编号；校验所需的随机串、目标和有效期全部取自服务端会话。伪造网页参数、缺少会话、旧挑战编号和过期挑战都无法通过。成功创建账号后立即消耗挑战，重复提交不能再次使用。数据库写入失败时保留未过期挑战。
- 网页仅校验当前输入，不会自动搜索答案。使用独立的纯 JavaScript SHA-256 校验器，普通 HTTP 和 HTTPS 均可实时检查，无须依赖仅在安全上下文中可用的 Web Crypto。
- 正式密码仍使用原来的 PBKDF2 存储，挑战哈希不用于替换密码存储算法。

实现文件：`RegistrationPasswordRules.java`、`RegistrationChallenge.java`、`registration-password-rules.js`、`registration-challenge.js`、`register.js`、`register.jsp` 和 `register.css`。本次无数据库结构修改。

```powershell
node --test src/test/js/*.test.cjs
# 使用能 require('playwright') 的 Node 环境；先运行 Java 测试生成 Jasper 渲染页面。
$env:PLAYWRIGHT_CHANNEL = 'msedge'
node --test src/test/browser/register.browser.test.cjs
```

Java 与 JS 使用同一份 `src/test/resources/registration-password-cases.json` 边界样例验证原有规则；SHA-256 校验器使用标准向量、Node 原生实现及 Java 实现核对，覆盖 Unicode 和块边界。注册接口测试验证非法密码、过期/缺失/伪造挑战不访问数据库，已解挑战只能成功使用一次，数据库失败保留挑战，合法 Unicode 密码仍原样哈希且可用于登录。浏览器测试验证十一项逐键反馈、HTTP 兼容、过期阻止提交和桌面/手机布局。成功路径使用测试构造的完整 48 比特目标，不降低正式难度，也不执行暴力搜索。测试不连接生产服务器。本次不生成 WAR。
